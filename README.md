
# Australia's AI Productivity Shock (2027–2030)

## Overview

This project is an interactive forecasting essay inspired by AI 2027. It examines how increasingly capable artificial intelligence systems could reshape the Australian economy between 2027 and 2030.

The central argument is that AI's largest economic effect will not be mass unemployment, but the rapid automation of cognitive tasks across professional industries. This will create a productivity boom while simultaneously generating distributional challenges, labour market disruption, and governance pressures.

The project combines:

- Economic theory
- Scenario forecasting
- Policy analysis
- Interactive visualisations
- AI-assisted research methods

to explore three alternative futures:

1. Baseline Transformation
2. AI Acceleration Boom
3. Fragmented Adoption

Users can interact with charts and decision trees to understand how capability improvements interact with regulation, labour markets, and industry structure.
